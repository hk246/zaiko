# 在庫管理システム - クイックスタートガイド

このフォルダには在庫管理システムが含まれています。

## 🚀 起動方法

1. **在庫管理システム.exe** をダブルクリック
2. 初回起動時、データベース保存場所を選択してください
   - 個人使用: デフォルト設定を推奨
   - 複数人で共有: ネットワーク上の共有フォルダを選択
3. ブラウザが自動的に開きます

## 📋 必要な環境

- Windows 10 以上
- メモリ: 2GB以上
- Pythonのインストールは不要です

## ⚠️ 注意事項

### このフォルダ全体が必要です
- **.exe単体では動作しません**
- フォルダ内の全ファイルを保持してください
- 移動する場合はフォルダごと移動してください

### 初回起動時の注意
- Windows Defenderが警告を出す場合があります
  - 「詳細情報」→「実行」で起動できます
  - これは正常な動作です（未署名のアプリのため）

### ショートカットの作成
デスクトップにショートカットを作成すると便利です：
1. 在庫管理システム.exe を右クリック
2. 「送る」→「デスクトップ（ショートカットを作成）」

## 🔧 トラブルシューティング

### ブラウザが開かない場合
手動でブラウザを開き、以下のURLにアクセス:
```
http://127.0.0.1:5000/
```

### データベースの場所を変更したい
1. 設定画面から変更できます
2. または実行ファイルと同じフォルダにある `config.json` を削除して再起動

### 「ポート5000が使用中」エラー
他のプログラムが5000番ポートを使用しています：
- 該当プログラムを終了してください
- またはPCを再起動してください

## 📁 データの保存場所

### 設定ファイル
```
dist\在庫管理システム\config.json  # 実行ファイルと同じフォルダ
```

### データベース（デフォルトの場合）
```
dist\在庫管理システム\instance\
├── inventory.db     # データベース
└── backups\         # バックアップ
```

### 共有フォルダを指定した場合
指定したフォルダにデータベースとバックアップが保存されます。
設定ファイル (config.json) は実行ファイルと同じフォルダに保存されます。

## 🆘 サポート

問題が発生した場合は、以下の情報を添えて報告してください：
- Windowsのバージョン
- エラーメッセージの全文（スクリーンショット推奨）
- 実行した操作の詳細
